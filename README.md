# All Mediatek Firmware Dump Kit

MediaTek (MTK) qurilmalaridan proshivka (dump) olish va mtkclient orqali ishlash uchun qulay vosita.

## Tizim talablari (Requirements)
* **Python 3.x:** Kompyuterda [python.org](https://www.python.org/) rasmiy saytidan yuklab o'rnatilgan bo'lishi kerak. O'rnatish jarayonida **"Add Python to PATH"** katakchasiga belgi qo'yish shart!
* **MTK Drayverlari:** `Drivers` papkasi ichidagi drayverlar Windows tizimiga o'rnatilgan bo'lishi kerak.

## Ishga tushirish yo'riqnomasi
1. Repozitoriyani yuklab oling yoki klonlang.
2. `Drivers` papkasiga kirib, operatsion tizimingizga mos drayverlarni o'rnating.
3. Buyruqlar satrida (CMD / PowerShell) loyiha papkasiga o'tib, zarur kutubxonalarni o'rnating:
   ```bash
   pip install -r mtkclient/requirements.txt
4. `start.bat` faylini ishga tushiring.
5. Ish yakunlanishini kuting...
