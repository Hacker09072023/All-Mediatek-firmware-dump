# All Mediatek Firmware Dump Kit

MediaTek (MTK) qurilmalaridan proshivka (dump) olish va mtkclient orqali ishlash uchun qulay vosita.

## Xususiyatlari
* MediaTek drayverlari to'plami (`Drivers`)
* `mtkclient` skriptlari
* Windows uchun avtomatik ishga tushirish fayli (`start.bat`)

## Ishlatish
1. Repozitoriyani yuklab oling yoki klonlang.
2. Kerakli drayverlarni o'rnating.
3. `start.bat` faylini ishga tushiring.
